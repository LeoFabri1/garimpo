Extract structured GPU deal data from a Brazilian Telegram promo message.
Return ONLY a JSON object with these fields:
- is_gpu: boolean
- model_raw: string or null (as written in the text, e.g. "RTX 5070 Ti")
- brand: string or null (ASUS, MSI, …)
- price: number or null (cash/PIX final price in BRL, not installment)
- price_method: "pix" | "boleto" | "card" | "unknown"
- coupon: string or null
- store: string or null
- condition: "new" | "used" | "refurb"
- confidence: "high" | "medium" | "low"

Rules:
- Never invent a model name that is not in the text.
- Prefer PIX / à vista price over installment amounts.
- If unsure whether it is a GPU deal, set is_gpu=false.
